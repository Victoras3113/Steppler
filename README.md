# Seppeler Gabelstapler-Disponent

Call all forklift drivers at once. The first available driver takes the order.

This is a home-screen web app (PWA) built with React, Vite and Tailwind, running on Supabase and hosted free on GitHub Pages.

**Setup:** see [SETUP.md](SETUP.md).

Local development (optional): `npm install`, copy `.env.example` to `.env.local`, then `npm run dev`.
